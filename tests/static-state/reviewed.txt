# Every static field of Spar's assemblies, with why it is safe (tests/static-state/StaticStateTests.cs).
# Spar keeps no process-wide mutable state: several apps run in one test process, and several projects' tasks in one
# MSBuild node. A new field is reviewed before it is added here. Format: assembly | field | readonly or writable | why.
# "Filled once" means a collection the static initializer fills and nothing writes again.
